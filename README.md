# game-zombie-portfolio

Game zombie simple yang dibuat menggunakan Unity dan C# dengan sistem State
untuk mengatur perilaku zombie.

## Fitur
- Zombie melakukan patrol
- Zombie mendeteksi player berdasarkan jarak
- Zombie mengejar player saat mendekat
- Zombie menyerang player jika player ada dalam jarak serang
- Sistem pengumpulan coin
